==================================================
桌面宠物 使用说明
==================================================

一、怎么运行
- Windows：双击 小仓鼠桌宠.exe
- Mac：双击 桌面宠物.command（或 .app）
- 第一次启动会冒一个欢迎气泡，之后就常驻桌面了。
- 当前内置 4 个形象：小仓鼠、罗小黑、罗小黑 · 3D 版、罗小黑 · 划船巡逻。
  默认启动哪个由 pets.json 的 "active" 决定（菜单里切换后会自动记住）。

二、基本操作
- 拖动角色：鼠标左键按住角色拖动（拖到副屏也可以）。
- 拖动信息面板：右侧深灰色信息框是独立窗口，左键按住它任意位置即可单独拖动，
  与角色互不干扰；角色移动、缩放、巡逻、跟随鼠标时，面板都留在原地不动。
- 信息面板默认停在屏幕右下角（距边缘 16px）。拖到哪儿就记住哪儿，
  位置存在 state.json，下次启动还在那里。
  想恢复默认：右键菜单 →「信息面板回到右下角」。
- 互动：左键单击角色，会随机播放小动作并冒对话气泡。
- 自动巡逻：右键菜单 →「自动巡逻」。开启后会自动换成「罗小黑 · 划船巡逻」
  形象，沿屏幕底部来回漂，水浪滚动、船桨一划一划、桨叶入水带水花；
  关闭巡逻会自动还原成你开巡逻之前选的形象（存在 state.json 里，
  巡逻中途直接退出程序、下次开机自启也能正确还原）。
  巡逻期间你手动在「切换宠物」里选别的形象也可以，手动选择优先，
  不会被强行拉回划船。
- 划船特效开关：右键菜单 →「划船水浪 / 船桨动画」，可单独关掉水浪和桨，
  只保留静态的划船形象；配置写在 config.json 的 boat_fx。
- 切换宠物：右键菜单 →「切换宠物（当前：xxx）」，列出所有形象，
  点一下立刻换形象、换对话文案、换托盘图标；选择会被记住，下次启动还是它。
- 调大小：鼠标放在角色上滚动滚轮；或右键菜单→调整大小。
- 透明度：右键菜单→透明度（100%~30%）。
- 置顶开关：右键菜单→窗口置顶（全屏看视频/打游戏觉得挡事，可临时关掉置顶或调半透明）。
- 退出：右键菜单→退出（桌宠没有关闭按钮，这是唯一出口；装了托盘组件的话托盘图标上也能退出）。

三、怎么添加新形象（重点，不用改代码、不用重新打包）
- 打开同目录的 pets.json，"pets" 数组里每一项就是一个形象。
- 两步加一个新形象：
  1) 把透明底 PNG 放进 assets/ 文件夹（建议高度 1000px 以上，全身图效果最好）；
  2) 在 pets.json 的 "pets" 数组里复制一条，改这几个字段：
       id         唯一标识，别和已有的重复（英文/数字）
       name       右键菜单里显示的名字
       image      图片路径，例如 "assets/我的新形象.png"
       dialogues  该形象用的文案文件（可以复用已有的）
       greeting   切换过去时它说的第一句话
       frames     可选，该形象专属动作帧目录（不填就用通用目录）
       height_px  可选，单独给这个形象指定显示高度
       fx         可选，填 "boat" 会启用划船水浪 + 船桨巡逻特效
- 保存后重启桌宠，右键菜单里就多出这一项。同一个角色可以有好几个形象
  （原画 / 3D / 不同表情），并列写进数组即可，顺序就是菜单顺序。
- "active" 记录当前选中的形象，程序切换时会自动写回这一个字段，
  不会覆盖你手写的其他条目和说明。想改默认启动的形象，直接改它。

四、对话文案在哪改
- 每个形象用自己的文案文件，由 pets.json 的 dialogues 字段指定。
  当前：小仓鼠 → dialogues.txt，罗小黑（3 个形象）→ dialogues_luoxiaohei.txt。
- 每行一句话，`# [分区]` 开头的是分区名：general（点击/随机气泡）、
  morning~night（整点报时）、daily（每日一言）、lv2~lv4（好感度解锁）。
- 改完保存，重启桌宠生效。也可以新建一个 txt，在 pets.json 里指过去。

五、动作帧（可选增强）
- 通用动作帧目录：assets/frames/，命名 walk_01.png、walk_02.png…（走路）
  和 idle_01.png…（空闲），桌宠巡逻/待机时会逐帧播放。
- 只想给某一个形象做逐帧动作：单独建个目录，把帧图放进去，
  然后在该形象的 frames 字段填目录名（例如 "assets/frames_lxh"）。
- 没有帧图也照样会动：程序化动画有呼吸基线 + 9 种随机小动作
  （伸懒腰、歪头、小蹦、点头、鼓气、三段跳等，默认每 8~20 秒触发一次）。
- 划船形象的水浪/船桨不需要任何帧图：boat_fx.py 按 24 个相位程序化
  预渲染（三层滚动波浪、断续高光、摆动船桨、入水水花、船尾泡沫），
  巡逻时约 1.05 秒一个划桨周期，静止时放慢到 1.9 秒；左右翻向、
  窗口缩放都会自动按新尺寸重新生成，动画全程窗口尺寸不变。

六、趣味组件有哪些、怎么开关
- 右键菜单→组件开关，勾选/取消即可，立刻生效。
- 默认只开了 4 个：AI 使用额度、下班倒计时、喝水提醒、天气。
- 全部组件：AI 额度 / 下班倒计时 / 喝水提醒 / 天气 / 迷你时钟（整点报时）/
  系统状态（CPU·内存·电量）/ 番茄钟 / 待办小纸条 / 摸鱼检测 / 每日一言 /
  投喂 / 好感度 / 跟随鼠标 / 快捷启动 / 音量控制 / 一键截图。
- 下班时间：右键菜单→「下班时间（当前）…」，填 18:00 这种 24 小时制，
  保存后立刻生效，也会写进 config.json。周末仍显示「今天不上班」。
- 其余详细配置（喝水目标、番茄钟时长、摸鱼灵敏度、快捷启动软件、
  随机动作间隔）在 config.json 里改，保存后重启生效。
  城市不用改文件也不用重启：右键→「天气与位置」→「手动设置城市…」，
  详见第十四节。
- 组件数据（喝水杯数、待办、好感度）存在 state.json，重启不丢。

七、关于「3D」的说明
- 本程序是透明置顶窗口里贴一张 2D 图片，靠代码做变换让它活起来。
  「罗小黑 · 3D 版」是 3D 渲染出来的立体形象（绒毛、体积光、次表面散射），
  视觉是 3D 质感，但它仍然是一张图：会呼吸、摇摆、跳跃，不能自由旋转视角。
- 想看到转身、换角度走路，需要为多个角度各准备一张动作帧图。
- 真·实时 3D（带骨骼的网格模型、任意角度旋转）要换整套渲染引擎，
  属于另一个项目，当前版本不包含。

八、Windows 被杀毒软件报毒怎么办
- 这是 PyInstaller 打包程序的常见误报（360、Windows Defender 都可能），
  不是病毒。选择"添加信任 / 允许运行"即可。
- 不放心的话，目录里附了全部源代码（pet.py），可自行检查。

九、Mac 提示"无法打开，因为无法验证开发者"怎么办
- 方法一：右键点程序→打开→在弹窗里再点"打开"。
- 方法二：系统设置→隐私与安全性→拉到底部点"仍要打开"。

十、怎么开机自启
- Windows：右键菜单→开机自启，勾选即可（写入注册表 Run 项，再勾一次取消）。
- Mac：系统设置→通用→登录项→添加本程序。

十一、常见问题排查
- 双击没反应：看任务管理器/活动监视器里有没有已在运行；有就先退出再开。
- 切换宠物没变化：确认 assets/ 里对应的 PNG 存在且是透明底；
  图片缺失时该形象会被自动跳过（不会出现在菜单里）。
- 角色边缘有粉/紫色描边、或一圈毛躁脏边：已从渲染管线根治。
  pet.py 的 _compose_chroma 不再按 alpha 混合到品红底，输出只有
  「角色原色 + 精确色键」两种值；旧版混合出的粉紫中间色不会再出现。
  若自己换图后仍有类似问题，检查图片是否为真透明 RGBA PNG、透明区无杂色，
  可用附带的 scripts/prepare_pet.py 或 prepare_flat_pet.py 重新处理。
- 点击/动作瞬间闪过黑色边框：已根治。角色窗 / 气泡 / 面板三个无边框窗口
  统一「先隐藏 → 配置完毕 → 再显示」；更关键的是角色窗口尺寸改为固定常量
  （基准 × 1.5 安全系数），动画全程不再 resize，窗口不会在动作第一帧
  清屏重绘而露出底色。
- 桌宠太小/太大：滚轮直接调，或右键→调整大小；4K 屏建议调"大"。
- 信息面板挡住内容：直接把它拖到别处（位置会记住）；或右键→透明度、
  组件开关关掉不需要的项。想复位就右键→「信息面板回到右下角」。
- 天气一直"暂不可用"：检查网络（用的是 wttr.in，免注册免 key）；
  右键→「天气与位置」→「立即刷新天气」可马上重试，失败后 5 分钟自动再试。
- 天气城市不对 / 换地方了：右键→「天气与位置」，手动设城市或开自动定位，
  详见第十四节。
- 系统状态组件没反应：需要先安装 psutil（改代码的高级用户：pip install psutil）。
- 想改代码：源码在 pet.py + boat_fx.py，改代码需要编程环境（Python 3.10+ 和 Pillow），
  不会改代码的话，直接用 exe 就行，所有常用修改（换图/文案/组件/加形象）都不需要动代码。

十二、内存占用
- 正常运行约几十 MB。如果发现异常飙高，先退出重开；组件不要一次全开。

十三、划船巡逻是怎么做出来的
- 形象图 assets/luoxiaohei_boat.png 是把你给的「罗小黑坐鸭子船」原图
  3D 化后抠成真透明 PNG：皮克斯风格绒毛、奶白鸭子船、橙红鸭嘴、
  小黄鸭玩偶、绿色脚丫；原图的小红书水印和玫红背景都已清掉。
  船底特意留了空白，给水浪和桨叶腾地方。
- 水浪、船桨、水花全部是代码画的，不是另一张图，所以能保证 24 帧
  严丝合缝、不会抖，也不怕左右翻向和改大小。所有线条都是不透明像素，
  配合 _compose_chroma 的两值合成，不会再出现之前那种粉边/毛边。
- 巡逻时船的晃动改成「随波起伏 + 缓慢摇摆」，而不是原来走路那种
  高频颠簸；信息面板依然独立，不会跟着船跑。
- 想换成别的船/别的角色：把新透明 PNG 放进 assets/，在 pets.json 里
  给那一项加 "fx": "boat" 就能复用整套水浪船桨特效；水线、桨架位置、
  摆幅等参数在源码 boat_fx.py 顶部集中定义，改起来很方便。

十四、天气的位置是怎么来的、怎么刷新
- 旧版本的真相：位置从来不是「定位」出来的。城市写死在 config.json 的
  city 字段（默认"北京"），程序启动时读进内存，之后每 30 分钟拿这个
  固定字符串去 wttr.in 拉一次天气；面板上显示的"北京"也只是把这个
  字符串拼进文案，不是接口返回的地点。所以位置永远不会自动变，
  想换城市只能手改 config.json 再重启程序。
- 现在有两种模式，右键→「天气与位置」随时切换：
  1) 手动城市（默认，行为和旧版一致）
     「手动设置城市…」输入中文/拼音/英文城市名（北京、Shanghai 都行），
     保存后立刻写进 config.json 并马上重新拉天气，不用重启。
  2) 自动定位（勾选「自动定位（按网络 IP）」）
     程序请求不带地名的 wttr.in 接口，由服务端按当前网络出口 IP 反查
     nearest_area，拿到经纬度和地名；之后天气改用经纬度查询，比城市名精确，
     也不会撞上同名地名。英文地名会翻成中文（Beijing→北京、
     Pootung/Shanghai→上海·浦东），结果显示在面板和菜单标题上。
- 「重新定位 / 刷新位置」：强制立刻重新按 IP 定位一次，适合换 WiFi、
  换网线、开关 VPN / 远程桌面之后用；点它会同时切到自动定位模式。
- 自动定位开启时，位置每 30 分钟随天气一起重新校准一次，换网络会自己跟上；
  定位失败不会崩，会保留上次有效坐标、回退到手动城市，下次循环再重试。
- 「立即刷新天气」：不等 30 分钟，马上重取一次当前位置的天气。
- config.json 里和位置有关的字段（一般不用手动改）：
    city            手动城市名
    city_auto       是否自动定位（true/false）
    city_coord      自动定位得到的 "纬度,经度"，缓存
    city_auto_label 自动定位得到的显示名，缓存
  缓存坐标会在关掉自动定位后保留，下次再打开可以立即使用。
- 注意：IP 定位拿到的是「网络出口」所在城市，不是 GPS 精确位置，
  精度大概到城市/区一级；走代理或公司专线时显示的是出口所在地。
  程序不申请系统定位权限、不读取任何 GPS / 基站信息。

十五、自动更新
- 右键→「检查更新（当前 vX.X.X）」可随时手动检查；程序启动约 8 秒后
  也会自动查一次（间隔在 update.json 的 start_delay_sec 里改）。
- 发现新版本会弹出本版更新说明，点「立即更新」后才开始下载，带进度条。
- 下载完会提示重启：程序先退出，由临时脚本替换文件再重新启动；
  旧 exe 会备份到 %TEMP%\DesktopPet-update\backup\。
- 更新不会清掉你的设置：组件开关、当前形象、自定义形象、面板位置、
  喝水记录全部保留；新版新增的形象会自动补进 pets.json。
  新版本新增的配置项由程序自动补默认值，不用手动改 config.json。
- 更新源在 exe 旁边的 update.json 里，repo 填 owner/repo。
  没填时程序跳过检查（不会报错）；改这个文件不需要重新打包 exe。
- 国内直连 GitHub 常超时，程序先试三个国内镜像，再直连兜底。
  检查失败只写日志 %TEMP%\DesktopPet-update.log，不影响桌宠使用。
- 源码运行（python pet.py）和 --selftest 不会自动检查更新。
- 维护者发版流程见 Docs/发布/更新与发布流程.md。
